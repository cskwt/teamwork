# أدوات الإنتاج — TEAMWORK

حزمة مستقلة من مشروع المحاسب الذكي، مخصّصة لمشروع **Teamwork**:

1. **الحضور والانصراف** — `/attendance`
2. **حاسبة التكاليف** — `/cost-calculator` (ليزر / ديجيتال)
3. **صانع القوالب** — `/template-maker` (أكياس، علب سحب، غطاء، قفل ذاتي، Tuck)

## التشغيل

```bash
cd ProductionToolsSuite
python3 -m pip install -r requirements.txt
python3 run_tools.py
```

ثم افتح: [http://127.0.0.1:8765](http://127.0.0.1:8765)

أزرار الأدوات في صفحة تسجيل دخول Teamwork تفتح هذا العنوان تلقائياً.

## متغيرات اختيارية

| المتغير | المعنى |
|---------|--------|
| `TOOLS_PORT` | منفذ السيرفر (افتراضي `8765`) |
| `TOOLS_USE_PARENT_DB=1` | استخدام قاعدة بيانات المحاسب إن وُجدت بجانب الحزمة |

## الملفات

- `run_tools.py` — سيرفر الأدوات
- `tools_core.py` — تحميل التطبيق وتقييد المسارات
- `vendor/app_simple.py` — نسخة كاملة من منطق الأدوات (حضور / تكاليف / قوالب)
- `assets/` و `Fonts/` — الأيقونات والخطوط
